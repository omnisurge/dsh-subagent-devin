# 实测记录（2026-11-07，macOS）

只记当时量到的事实，不写结论性建议。复现命令附在后面。

## 环境

- macOS（arm64），Devin 桌面版已登录，账号 `Example Account`
- CLI：`/Applications/Devin.app/Contents/Resources/app/extensions/windsurf/devin/bin/devin`
- 凭据文件：`~/.local/share/devin/credentials.toml`，mode **644**

## ACP 交互

| 观察 | 结果 |
|---|---|
| `initialize` | 成功，返回认证方式（浏览器登录）与 agent 信息 |
| 未认证直接 `session/new` | **成功**（会话能建） |
| 未认证直接 `session/prompt` | 报错，错误码 `-32000`，消息提示需要登录 |
| `authenticate{devin-browser}` | 每次调用**都弹一个浏览器窗口**；一轮里弹出 5～7 个 |
| 认证后 `session/new` | `configOptions.model.options` 才有内容 |
| 认证前该字段 | `currentValue` 是占位值，`options` 为空数组 |

结论性事实：**可用模型列表必须在认证之后取**，认证前拿到的是占位。

## 密钥面

| 前缀 | 来源 | 可否用于 ACP |
|---|---|---|
| `devin-`（189 字符） | 凭据文件里的 API key 字段 | 可用（跑通过一轮） |
| `apk_user_…` | 平台「API keys (legacy)」页 | 不可用 |

在 CLI 二进制（约 194 MB）里检索字面量：`apk_` **0 次**，`WINDSURF_API_KEY` 4 次。

## CLI 行为

| 场景 | 观察 |
|---|---|
| `devin auth status` | 约 2.1 秒返回；输出含 `Logged in (via Devin).`、`File: <路径>`、`Name: <账号>` |
| 已登录时再 `devin auth login` | 拒绝：要求先 logout |
| `devin auth login` 无参数 | 交互式三选一菜单；**不打印 URL**，由它自己打开浏览器 |
| 向登录 TUI 管道输入回车 | 判为取消（没有 TTY 就驱动不了） |
| **子进程 stdin 留成管道** | **命令一直不退出**，8 秒超时被杀，输出为空 → 被误判成「未登录」 |
| 子进程 stdin 接 `/dev/null` | 正常 2.1 秒返回 |

最后两行是本批修复的根因：读 CLI 状态必须把 stdin 接成 `/dev/null`（`spawn` 的 `stdio: ['ignore', …]`），
`execFile` 默认留管道，在这个 CLI 上会卡死。

## 会话配置项的传输形状

`session/new` 返回的 `configOptions` 是**数组**，每项带 `id`：

| 观察 | 结果 |
|---|---|
| 结构 | 数组，2 项：`id: 'mode'`、`id: 'model'` |
| 每项字段 | `id` / `name` / `description` / `category` / `type: 'select'` / `currentValue` / `options[]` |
| mode 的可选值 | `accept-edits`(Code) / `ask`(Ask) / `plan`(Plan) / `bypass`(Bypass Permissions) |
| model 的可选值 | 认证后 2 项，认证前空数组 |

早期实现按「对象键」读（`configOptions.model`），真机上模型列表恒为空、当前模型为空——
因为数组下面没有 `model` 属性。现在统一走归一化（数组→按 id 索引），替身也改成数组形状。

## 一次真实的「已登录但显示未连接」

| 观察 | 值 |
|---|---|
| 凭据服务里的密钥前缀 | `apk_us`（平台接口密钥，不是 CLI 凭据） |
| 探测结果 | `authenticated: false`，错误含 `Authentication required: invalid api key` |
| 自动导入有没有兜底 | **没有**——它只在“库为空”时跑，库里有个用不了的值就永远不触发 |

教训：只判断“库里有没有值”不够，还要判断“这个值是不是已知不可用的类型”。
现在库里是 `apk_` 前缀时会改走 CLI 导入并替换；认证失败且密钥来自库里时也自愈一次（有界）。

## 复现命令

```sh
D="/Applications/Devin.app/Contents/Resources/app/extensions/windsurf/devin/bin/devin"
"$D" auth status                     # 观察输出字段与耗时
"$D" models list --format json | head -40
# ACP 探测：本仓 test/fake-devin.mjs 是替身；真机探测走插件启动时的 probe
```

不要在复现过程中打印密钥值；只需要前缀、长度和 sha256 前 12 位做比对。
